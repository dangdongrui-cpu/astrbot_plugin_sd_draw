引擎

手动填引擎目录 → 一键安装/启动/停止。路径保存在配置里。

引擎目录

一键部署会把模型拷进它的 models 子目录；一键启动从这里找可执行入口。

安装

本地引擎二选一：ComfyUI 可后台一键装官方便携包；WebUI 走 git 流程或整合包。

ComfyUI 官方便携包：github.com/comfyanonymous/ComfyUI（Releases 页有 win 版压缩包）

WebUI（Forge）：git clone stable-diffusion-webui-forge ，进目录跑 webui.bat 完成安装。

启动 / 停止

启动后会弹出引擎自己的命令行窗口，带 --api；就绪后概览页红绿灯变绿。停止=终止进程树。

禁词表

原始描述与润色结果双重过筛，撞词打回重写。NSFW 闸关着时此表管用。

润色预设

每套预设 = 润色四件套 + 三档风格指令，出图用「使用中」的那套。展开卡片可改，改完保存整套；模型参数预设的"提示词风格"会在此之上附加。

身份注入块（PERSONA_LOAD 段）是钝化审核的骨架，删了可能退回敏感审卡。至少保留一套预设。
